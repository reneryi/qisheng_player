## 说明

`v1.3.0` 是一次面向长期使用体验的稳定性与性能更新，重点收敛播放页结构、降低后台写入和封面处理开销，并改善在线歌曲、歌词与封面的匹配质量。

## 改进与优化

- 精简正在播放页面的失效模式与重复操作，统一播放状态和组件结构。
- 封面读取改为共享 Rust 解码结果，艺术家、专辑和歌曲视图可复用缓存，减少重复读取与解码。
- 设置、播放次数等高频数据采用延迟合并和原子写入，退出应用前自动刷新待写数据。
- 在线歌曲搜索并行请求数据源，并加入 Unicode 字符距离、歌手约束和歌词最低置信度，降低错配概率。
- 在线封面失败结果持久化七天，避免反复请求已经失效的资源。
- 歌词默认通过透明度区分景深，视觉效果档位可按需启用静态模糊。

## 问题修复

- 规避 Flutter `3.41.x` Windows 引擎在无障碍工具读取虚拟列表 Tooltip 时持续输出 `AXTree` 更新错误的问题，同时保留“更多”等操作的语义标签。
- 修复 GBK 编码 CUE 文件无法读取的问题。
- 修复独占模式初始化失败后状态回滚不完整，以及静音后恢复音量异常的问题。
- 修复 FFI 返回内存未释放和 Rust 索引并发写入可能损坏的问题。
- 设置、播放列表、播放统计和元数据覆盖数据统一采用原子写入；元数据编辑会同步更新 Rust 索引。

## 测试与验证

- Flutter 静态分析通过。
- Flutter 全量 `138` 项测试通过。
- Rust 格式、检查和测试通过。
