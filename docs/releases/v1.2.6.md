# Qisheng Player v1.2.6

发布日期：2026-05-24

这是 `v1.2.x` 的更新检查体验补丁，修复发布新版本后旧客户端需要等待很久才识别到更新，手动检查时看起来一直转圈的问题。

## 修复

- 更新检查现在会在获取到第一个可用的新版正式 Release 后立即返回，不再等待 GitHub Release 列表全部分页加载完成。
- 保留对历史 fork Release、预发布版本、草稿版本和无效版本号的过滤，避免再次误报旧仓库版本。
- 手动检查更新与启动自动检查共用同一套快速判断逻辑。

## 验证

- `flutter test test\settings_page\startup_update_prompt_test.dart`

## 发布产物

- `Qisheng-Player-v1.2.6-Windows-x64.zip`
- `Qisheng-Player-v1.2.6-Setup-x64.exe`

## 升级建议

- `v1.2.4` 和 `v1.2.5` 用户建议升级到 `v1.2.6`，以获得更快、更稳定的更新检查体验。
