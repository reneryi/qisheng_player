# Qisheng Player v1.2.5

发布日期：2026-05-24

这是 `v1.2.x` 的桌面歌词稳定性补丁，修复桌面歌词在播放途中停止刷新、切到下一首后仍显示前一首歌名的问题。

## 修复

- 修复主程序向桌面歌词子进程连续发送多条消息时，JSON 消息可能黏连导致桌面歌词通信流卡住的问题。
- 桌面歌词现在按“一行一条 JSON 消息”的协议接收更新，遇到异常坏帧会丢弃该帧并继续处理后续消息。
- 自动切歌后会重新发送当前歌词行，避免桌面歌词只显示歌名、不显示歌词。
- 收窄连续切歌时的异步发送时序，避免旧回调把桌面歌词更新成错误歌曲信息。

## 升级建议

- 使用桌面歌词的用户建议升级到 `v1.2.5`，以避免播放一段时间后桌面歌词停止刷新或残留上一首歌名。
