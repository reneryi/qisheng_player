# Qisheng Player v1.2.3

发布日期：2026-05-23

这是 `v1.2.x` 的小补丁更新，重点修复桌面歌词切歌后偶发不显示歌词，以及启动自动检查更新不稳定的问题。

## 修复

- 修复正常播放结束自动进入下一首时，桌面歌词偶发只显示歌名、不显示歌词的问题。
- 修复启动自动检查更新只依赖 GitHub Release 列表第一项的问题，避免预发布版本或列表顺序导致正式更新漏检。
- 修复版本比较过于宽松的问题，无效 tag 或带预发布后缀的 tag 不再参与正式版自动更新判断。
- 增强曲库索引更新容错，避免损坏的 `index.json` 触发 Rust panic。

## 改进

- 启动检查更新增加短重试，网络或 GitHub API 临时失败时不立即放弃；无新版本或最终失败时仍保持静默。
- 设置页手动检查更新与启动检查复用同一套正式 Release 选择逻辑。
- 桌面歌词切歌时会在更新歌名后重新发送当前歌词行，降低异步加载和消息顺序造成的显示空窗。
- 专辑封面主色调排序逻辑改为更明确的权重降序排序。
