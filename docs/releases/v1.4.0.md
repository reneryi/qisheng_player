## 说明

`v1.4.0` 是一次重大功能与交互体验升级。本版本重构了全新的现代双栏“音乐编辑”工坊体系与底层持久化引擎，全面升级了扎实饱满的实心圆润图标与物理微动量控键动效，优化了默认背景材质与桌面歌词体验，并对全链路系统稳定性与并发鲁棒性进行了全面加固。

## 现代双栏“音乐编辑”工坊体系

- **双栏现代弹窗架构**：基于 `ModernDialogFrame` 打造 980px 经典双栏布局，彻底废除单栏纵向深滚与各字段前置复选框，采用纯净表单与自动脏数据（`isDirty`）判定。
- **左栏核心元数据与封面管理**：
  - 集成 140x140 高清封面预览卡片，支持本地选取替换与一键清除。
  - 提供标题、艺术家、专辑、专辑艺术家、音轨、碟号、年份、流派等紧凑美观的网格表单。
- **右栏多源在线检索与一键采纳**：
  - 集成网易云、酷狗、QQ 音乐多源在线检索，支持来源过滤 Chip。
  - 高质感候选匹配卡片展示封面、标题、歌手、专辑与匹配度评分，支持“一键智能采纳”。
  - 彻底解决 CDN 403 防盗链阻断与空 mid 404 异常。
  - 严格解耦单曲内嵌封面、专辑画册与艺术家头像三者的物理存储与生命周期，单曲采纳不再污染全局画册。
- **歌词工坊与实时预览**：
  - 支持在线歌词预览、微调编辑、格式化导出与内嵌写入切换。
- **底层物理持久化与即时热同步**：
  - Rust 事务引擎加固：支持 MP3 (ID3v2)、FLAC (Vorbis Comment)、M4A/AAC (MP4 Ilst)、OGG 及 CUE 虚拟分轨物理写入。
  - 针对 Windows 文件占用引入指数退避重试循环，消除并发读写冲突。
  - 破解 Provider Selector 缓存抑制，保存成功后底栏、曲库与歌单视图即刻热刷新。

## 饱满圆润图标与物理微动量交互

- **实心圆润视觉规范**：全应用统一注入 Material Symbols Rounded 高权重实心图标主题，告别生硬锐利的线框质感。
- **核心控键免遮挡准则 (No-Tooltip Policy)**：底栏 5 个高频播放控制键（随机播放、上一首、播放/暂停、下一首、循环模式）移除浮动气泡，杜绝悬停时遮挡进度条与曲名。
- **解耦物理微动量矩阵**：
  - 独立配备 `_hoverController`（160ms~180ms，`Curves.easeOutCubic`），杜绝单帧阶跃。
  - 上一首/下一首轻量向左/向右微冲量与微弹簧回弹。
  - 随机播放点击瞬间触发 -90° 旋转弹性势能；循环模式轻量上弹移与呼吸式平滑发光指示点。

## 视觉、材质与桌面歌词优化

- **默认背景材质调优**：
  - 夜间采用 135° 深邃苍青微流光渐变，沉浸优雅。
  - 日间采用 135° 温润和纸白渐变，柔和护眼。
- **页面边缘自适应**：优化通用页面顶部与边距，解决艺术家和专辑页首行卡片在边缘悬浮时可能出现的裁切瑕疵。
- **桌面歌词与独立配置**：解决桌面歌词启动与设置弹窗闪白问题，重构独立配置子窗口与圆润质感按钮风格。
- **元数据与图像修复**：修复超大像素头像保存失败、恢复歌曲封面联动失效及封面下载偶发失败问题。
