# Qisheng Player v1.2.7

发布日期：2026-05-30

这是 `v1.2.x` 的歌词同步修复补丁，重点修复播放器隐藏到托盘或窗口恢复后，顶部歌词、右侧歌词预览和播放详情页歌词滚动可能卡住的问题。

## 修复

- 修复歌词行状态只向前推进导致播放位置回退、循环或恢复窗口后停在旧行/最后一句的问题。
- 窗口从托盘恢复或重新获得焦点后，会主动补发播放进度、播放状态和当前歌词行。
- 增强顶部歌词、右侧歌词预览和播放详情页歌词列表的恢复滚动能力，避免隐藏窗口期间错过滚动回调后无法重新定位。
- 如果隐藏窗口期间底层播放进度定时器异常失效，恢复时会重新同步播放快照。

## 验证

- `flutter analyze`
- `flutter test`
- 手动验证：播放中隐藏到托盘一段时间后恢复，顶部歌词、右侧歌词预览和播放详情页歌词滚动均能正常同步。

## 发布产物

- `Qisheng-Player-v1.2.7-Windows-x64.zip`
- `Qisheng-Player-v1.2.7-Setup-x64.exe`

## 升级建议

- 建议所有 `v1.2.x` 用户升级到 `v1.2.7`，尤其是经常最小化到托盘播放音乐的用户。
