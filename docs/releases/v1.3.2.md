## 说明

`v1.3.2` 是一次面向播放器视觉一致性、歌词定位和日常播放体验的综合更新。版本重点提升封面动态取色的准确度，引入三色极光流体着色器，并修复首次播放波形、歌词居中、暗色图标和调试热重启等问题。

## 动态视觉升级

- 封面取色采用面积加权聚类、中心区域权重和 `OKLab` 感知距离，过滤透明像素、低占比杂色和视觉近似色。
- 调色板明确分配主色、次色、强调色和柔和色；颜色不足时生成同色系变体，中性封面始终保持灰阶。
- 设置面板、菜单和玻璃表面使用当前封面的柔和动态染色，并分别优化日间、暗色模式的亮度与对比度。
- 极光流体模式使用三色片元着色器表现染料扩散、卷曲和交融，支持平滑轨迹、`600ms` 切歌过渡与效果档位降级。
- 着色器加载失败或设备不支持时自动使用 Flutter 原生不规则流体路径，不影响播放器启动。

## 播放与歌词体验

- 修复恢复上次会话后首次点击播放时波形动画不启动的问题。
- 波形进度条只在实际绘制区域响应点击、拖动、悬停和提示，两侧空白不再误触进度。
- 播放页与底部播放器的长标题支持横向滚动，英文下伸字符不会被裁切。
- 当前歌词按真实渲染区域定位：大屏居中、紧凑布局保持原位置，切换窗口布局时立即重新对齐。
- 首句、中间行、末句和翻译歌词共享稳定滚动策略；快速连续切行只保留最新定位请求。
- 统一非当前歌词的景深模糊，同时保留逐字歌词、翻译、高亮、透明度和缩放效果。
- 音乐页工具按钮改为无圆形底的沉浸式样式，暗色模式图标恢复浅色前景。

## 设置、窗口与兼容性

- 自定义字体支持导入 `TTF`、`OTF`、`TTC`；字体经 Rust 校验后复制到应用托管目录，原文件移动后仍可使用。
- “UI 视觉风格”仅保留玻璃模式；Windows 背景材质仅保留“自动、云母、极光流体、关闭”。旧枚举配置会自动迁移。
- 选择极光流体时自动开启动态主题；切回其他材质后不会擅自关闭动态主题。
- 最大化、普通窗口和全屏使用独立布局间距，状态切换后即时刷新。
- 播放详情页顶部移除重复的桌面歌词入口，桌面歌词服务、底部按钮和快捷键保持可用。
- 全局 Tooltip 字号调整为 `14px`，歌词来源按钮补充“选择歌词来源”提示。
- 修复 Flutter 热重启后 BASS 插件已加载状态被误判为错误的问题。
