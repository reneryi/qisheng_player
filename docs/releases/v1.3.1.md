## 说明

`v1.3.1` 是一次 Windows 窗口行为修复更新，解决播放器被恢复为最小尺寸后无法正常拖动缩放的问题，并完善窗口尺寸和最大化状态的持久化。

## 问题修复

- 修复窗口处于 `507 × 507` 最小尺寸时，边缘和四角无法拖动缩放的问题。
- 修复最大化退出后重启未恢复最大化状态的问题。
- 普通窗口尺寸与最大化、全屏状态分开保存，避免占屏尺寸覆盖最后一次普通窗口尺寸。
- 校验持久化的窗口尺寸；格式错误、非有限数值、负数或低于最小尺寸时自动回退。

## 体验优化

- 默认窗口尺寸调整为 `1461 × 898`，首次启动或窗口配置异常时完整展示音乐列表、歌词预览与底部播放控制。

## 测试与验证

- Flutter 静态分析通过。
- Flutter 全量 `142` 项测试通过。
- Windows Release 构建通过。
- 便携压缩包与 Inno Setup 安装程序生成并校验通过。
