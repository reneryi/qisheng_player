# Qisheng Player v1.2.4

发布日期：2026-05-23

这是 `v1.2.x` 的紧急补丁更新，修复 v1.2.3 自动检查更新可能误读历史 fork 正式版本的问题。

## 修复

- 自动检查更新现在只接受栖声发布线：Release 名称需为 `Qisheng Player ...`，或附件名需为 `Qisheng-Player-v...`。
- 即使仓库中存在旧 `coriander_player` / fork 历史正式 Release，也不会再被判断为栖声的新版本。

## 发布侧修正

- 已将仓库中历史 fork 的 `v1.6.1`、`v1.6.2` Release 标记为预发布，避免已安装的 v1.2.3 客户端继续误报。

## 验证

- `flutter test`

## 发布产物
