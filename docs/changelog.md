## [1.3.1] - 2026-07-25 - 窗口尺寸恢复修复

### 问题修复

- 修复窗口缩小到最小尺寸后无法通过边缘和四角拖动调整大小的问题。

## [1.3.0] - 2026-07-12 - 稳定性、性能与在线匹配优化

### 改进与优化

- 移除 Studio 模式、迷你播放条和重复播放操作等失效链路，收敛 Now Playing 状态与组件结构。
- 降低封面动画、设置保存和播放次数写入的后台开销；应用退出前会刷新待写数据。
- 歌词默认改用透明度区分景深，并提供仅在视觉效果档位生效的可选静态模糊。
- 三档封面尺寸共享一次 Rust 读取与解码，艺术家、专辑和歌曲视图复用同一缓存结果。
- 在线歌曲匹配改用 Unicode 字符距离、并行数据源和歌手约束；自动歌词采用最低置信度门槛。
- 在线封面失败记录支持七天持久化缓存，避免对失效资源反复发起请求。

### 问题修复

- 规避 Flutter `3.41.x` Windows 引擎在无障碍客户端读取虚拟列表 Tooltip 时产生的 `AXTree` 更新错误，同时保留列表操作的语义标签。
- 修复 GBK 编码 CUE 文件读取失败，以及独占模式初始化失败时状态回滚不完整的问题。
- 修复静音后恢复音量异常、FFI 返回内存未释放和索引并发写入可能损坏的问题。
- 设置、播放列表、播放统计和元数据覆盖数据改为原子写入；Rust 索引写入增加串行锁。
- 元数据编辑同步更新 Rust 索引，避免重新扫描后编辑结果丢失。

### 工程质量

- Flutter Rust Bridge 绑定更新至当前接口，补充匹配、封面缓存、播放统计和原子写入测试。
- Flutter 静态分析、全量测试、Rust 检查与测试，以及 Windows Debug/Release 构建全部通过。

### 发布

- 版本号更新为 `1.3.0`。
- GitHub Release 附件：`Qisheng-Player-v1.3.0-Windows-x64.zip`、`Qisheng-Player-v1.3.0-Setup-x64.exe`。

## [1.2.9] - 2026-06-25 - 页面动效重构与卡死修复

### 问题修复

- **修复点击控制栏卡死**：重构导航历史记录 `rememberLocation` 的通知逻辑，由原来的同步 `notifyListeners()` 改为通过 `WidgetsBinding.instance.addPostFrameCallback` 在当前帧 build 结束后进行异步刷新通知。这完美解决了由于 GoRouter 构建详情页时同步向主界面发送状态通知而造成的 UI 重绘死锁。
- **修复 Hero 返回飞越重合错位**：优化了 Hero 状态机制。通过 `disableHero: true` 彻底规避了详情页内底部控制栏同名 Hero tag 冲突。同时锁定底层转场期间的主页面背景物理坐标，确保飞回时大封面高拱飞行能百分之百精准落入底层控制栏原本的封面卡槽中，消除了闪跳。
- **回填被遗漏的底栏淡显动效**：在 `page.dart` 中重新添加了因重构被意外删除的 `AnimatedOpacity` 组件，恢复了底栏在详情页中显示/隐藏时的淡入淡出动画，并修复了对应的组件测试查找错误。
- **对齐全局转场时间**：将播放详情页卡片滑入转场的时间修正为与普通主路由一致的 `520ms`（入场）和 `380ms`（出场），不仅让整体动效在感官上节奏更契合，也修复了相关测试断言。

### 发布

- 版本号更新为 `1.2.9`。
- GitHub Release 附件：`Qisheng-Player-v1.2.9-Windows-x64.zip`、`Qisheng-Player-v1.2.9-Setup-x64.exe`。

## [1.2.0] - 2026-05-05 - 转场动画与玻璃层稳定性

### 亮点与新增特性

- **艺术家头像共享元素转场**：艺术家页进入详情页时，艺术家头像会像专辑封面一样平滑移动到详情页对应位置，返回时反向衔接。
- **页面切换动画统一**：旧页面在新页面进入时同步模糊、下移、轻微缩放并淡出，减少此前模糊后突然消失的生硬感。

### 改进与优化

- 保留专辑页进入/返回详情页的封面 Hero 动画，并将其导航守卫扩展为通用 artwork Hero 机制。
- 文件夹页移除列表项悬浮路径 Tooltip，避免悬浮层和玻璃背景叠加造成闪烁。
- 设置页的分组面板使用稳定玻璃策略，避免控件 hover 时反复触发背景模糊重绘。
- `AppSurface` 支持按场景选择背景模糊行为，复杂列表和设置页可以优先使用稳定玻璃表现。

### 问题修复

- 修复文件夹页鼠标掠过文件夹选项时可能出现的频闪。
- 修复设置页控件 hover 时可能出现的类似频闪。
- 修复旧页面路由转场只模糊、不连续淡出导致的突兀消失。

### 发布

- 版本号更新为 `1.2.0`。
- GitHub Release 附件：`Qisheng-Player-v1.2.0-Windows-x64.zip`、`Qisheng-Player-v1.2.0-Setup-x64.exe`。
- `v1.1.0` 用户启动播放器后会检查 GitHub 最新正式 Release；当 `v1.2.0` 发布为最新正式版本时会弹出更新提示。

## [1.0.0] - 2026-04-29 - 栖声品牌化与全面升级

本项目自上游 [coriander_player](https://github.com/Ferry-200/coriander_player) Fork 后，经历了深度的二次开发与优化。`1.0.0` 是栖声品牌化后的第一个完整正式版本，标志着播放器在视觉交互与稳定性上的全新起点。

### 🌟 亮点与新增特性

- **品牌重塑**：将应用正式命名整合为 `qisheng_player` (栖声)，全新设计的圆形应用图标与安装包命名。
- **现代化视觉重构**：全面引入 **玻璃拟态 (Glassmorphism)** 视觉语言，统一主界面、底部播放栏、侧边栏、页面面板的毛玻璃效果。
- **Apple Music 风格动效**：
  - 动态流体背景：背景随当前播放专辑的主色调缓慢弥散流转。
  - Hero 共享元素转场：专辑页到详情页的封面图片实现无缝飞跃动效。
  - shared-axis 页面切换：侧边栏切换时加入平滑的淡入淡出过渡。
- **沉浸式 Now Playing (正在播放) 页面**：
  - 支持沉浸式与专业式两种布局模式，保留精美的竖向/横向歌词。
  - 增强逐字歌词动效：当前行支持字号、字重放大及透明度与发光变化。
  - 右侧歌词预览栏：音乐页新增可悬浮展开的迷你歌词栏，随时查看滚动歌词。
- **增强型曲库与文件夹管理**：
  - 文件夹管理迁移至独立全屏页面，操作更加直观。
  - 完善 A-Z/拼音索引、当前播放快速定位、多维度排序及灵活的视图切换。
- **专业级音频控制**：
  - 接入 BASS 库扩展，暴露 FFT 频谱数据，为未来全局音频可视化打下基础。

### 🛠️ 改进与优化

- **性能优化**：引入 `UiEffectsLevel` 效果档位，默认 `balanced` 模式下智能降低模糊成本与动画帧率，有效消除主界面卡顿。
- **布局微调**：
  - 侧边栏改造为悬浮胶囊形态，选中项增加动态强调色。
  - 优化顶部导航与标题栏：新增独立后退/前进按钮，动作按钮更贴近右侧，视觉层级分明。
  - 底部播放器重排：随机播放、循环模式拆分为独立控制按钮，音量调节升级为胶囊滑杆。
- **智能取色与对比度**：动态专辑取色现仅影响强调色与背景氛围，确保了文本的高对比度和可读性。

### 🐛 问题修复

- **彻底消除中文乱码**：
  - 修复底层 Rust 索引时常见的 UTF-8 / Latin-1 / Windows-1252 解码冲突引发的日韩中文乱码。
  - 补全 Dart 层的显示兜底机制，自动清理残留控制字符和 `锟斤拷`，无名文件统一显示为“未知艺术家/专辑”。
  - 修复应用内遗留的英文/乱码文本（如“文件夀”、“ReplayGain”翻译修正）。
- **稳定性修复**：
  - 修复左侧栏快速切页时因 `AnimatedSwitcher` `GlobalKey` 冲突导致的 UI 卡死。
  - 修复播放器最大化切换时，音量/进度 Slider 宽度坍缩到 0 导致的程序崩溃。
  - 修复同步歌词进度插值错误，确保逐字高亮精准同步。
  - 修复部分旧版本偏好设置引发的异常，增强配置向后兼容性。

## 历史版本说明

`1.0.0` 版本整合了旧的 `1.7.x` (原 coriander_player 迭代记录) 预发布记录。旧版本的核心功能如多文件夹扫库、全局快捷键、CUE 完美分轨支持等均在 `1.0.0` 中得到了保留和深度优化。

后续版本将继续遵循语义化版本号 `1.x.y` 进行稳定迭代。
